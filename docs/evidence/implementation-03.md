# 推荐首屏与界面对照完善

## 本轮范围

在用户与 Anti Gravity 已有未提交实现上继续开发，保留既有账号、Keychain、分类/榜单接口、下载、历史与播放器进展。没有重置工作区或提交合并。后端已支持真实热播候选，本轮没有新增或修改服务接口。

## 已完成

- `App.tsx` 默认进入独立 `RecommendView`，不再将目录页当推荐首屏。推荐占满内容区，保留系统窗口栏；侧栏使用统一SVG图标、弱底色选中态，日历归入新剧页签，播放探针不再占产品导航。
- 推荐页沿既有 `/discover/rank` 获取真实热播候选，真人剧切换对应真实榜单；独立 feed 不共用发现页全局榜单状态，避免跨页串数据。分页、去重、取消和旧响应隔离均有测试。不是个性化推荐接口；“关注”使用本地追更数据，没有虚构关注流/评论/社交计数。
- 推荐页接入真实 `/play`、原生 Video 和已有解密链路，支持上下/滚轮切剧、单视频生命周期、暂停、进度拖动、选集、倍速/质量、静音/全屏、收藏/点赞/追更、复制真实剧集链接和下载。账号写入沿用既有本地资料/下载队列语义，没有新增云端写回承诺。
- 错误/加载层不阻挡顶部频道；单片播放失败有重试和下一部，不将上游失败伪装为成功。切频道清除旧feed错误，避免空关注页残留推荐加载失败。离页取消请求并卸载Video。
- 共用 `PosterCard` 改为海报本身可播放，取消卡片盒子和重复播放按钮；海报文字单行省略、底层元数据，保留详情入口。`FilterChip` 改选中描边圆pill，未选项扁平。语义主题补媒体专用颜色，页面不硬编码颜色。
- 找剧搜索移到页头右侧，筛选行扁平化、完整枚举可见/可滚动，修复静态选中快照；新剧/日历页签和受众筛选；排行榜采用横向类型和左侧已支持的热播榜。海报随可用宽度计算，当前桌面七列。
