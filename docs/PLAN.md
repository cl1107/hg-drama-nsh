# 开发计划

## 目标与完成定义

以 NSH TSX 构建红果短剧客户端。首期 macOS 原生窗口可运行，使用真实来源完成搜索、详情、分集、播放、切集、断点续播、扫码登录和本地资料管理；界面还原参考截图的布局与交互。全平台指 macOS、Windows、Linux、iOS、Android、Web 的长期目标，按平台逐个验收，不能以 macOS 可用替代全平台可用。TUI 不在本次视频客户端范围。

范围分三层：MVP 是可播放的核心闭环；macOS 首期完整版本再覆盖推荐、分类、榜单、新剧、日历、收藏/点赞、追更/预约和下载；平台扩展最后执行。未知在线接口属于首期待解任务，不能默认为上游已有，也不能永久藏到“以后”。

## 阶段与任务

当前 P0a 的安装/check/build/test/原生宿主启动已完成，视觉验收被锁屏阻塞；P0b 已通过基础加密向量，P0c 已通过 Cookie/重定向探针。P1/P2 已有局部目录实现，尚未达阶段验收。新增：P0b已完成一集真实HEVC/CENC→AVPlayer加载/进度/seek及Apple画面提取；P2/P3已接播放/选集入口。当前开发后端为本机Node24服务，尚非正式跨平台媒体后端。记录见 `evidence/implementation-02.md`。其余任务仍待办。工期按通过验收的任务包估计，暂不以日历日期承诺；P0 结束后再估算媒体与登录成本。

| 阶段 | 任务与交付 | 依赖 | 通过标准 |
|---|---|---|---|
| P0a 工具 | 固定 NSH 0.5.1，生成原版 TS 模板、项目配置、版本与命令记录 | 无 | check/build/test 基线通过，macOS 打开模板窗口 |

| P0c 登录探针 | 二维码、CookieJar、重定向、资料验证、系统安全存储能力 | P0a | 用户确认后登入、重启恢复、退出清除；失败保留原因且不落明文 |

| P5 发现页面 | 推荐流、找剧筛选、榜单、新剧、日历 | P0d + P2 | 接口真实参数控制内容与分页；无接口的条目给明确状态，禁止假榜单 |
| P6 我的与下载 | 追更/预约、管理批量选择、下载队列/暂停/恢复/删除、设置 | P3 + P4 + P0d | 本地追更与云预约分清，任务可恢复、不误删、离线媒体可播 |
| P7 macOS 发布验收 | 图像对照、性能、长播、离线、账号隔离、可安装包与依赖声明 | P1–P6 | VALIDATION 全部首期必需项有证据；签名/公证缺项明确标记 |
| P8 平台扩展 | Windows→Linux→iOS/Android→Web，每个平台独立适配和验收 | macOS 闭环稳定 | 对应媒体、凭证、文件、后台能力实测，不能只通过编译 |

P0b/P0c 的能力阻塞优先级高于所有页面美化。MVP 可在 P4 完成后交付本机体验；P5/P6 未完成时整体首期仍未完成。

## P0 关键决策门槛

| 问题 | 事实来源 | 失败后的下一步 |
|---|---|---|
| QuickJS crypto 是否能承载签名与密钥派生 | 0.5.1 类型、运行测试、上游向量 | 缩小不兼容 API；证明必须原生后提出模式取舍 |
| Set-Cookie/多重 Cookie/重定向能否控制 | NSH fetch 实际响应与测试服务 | 看原生会话 API；不能用 document.cookie 代替 HttpOnly |
| Video 能否带必要请求头并 seek | 生成声明与 macOS 播放探针 | 桌面受限本机媒体服务，或注册原生播放器 |
| CENC 处理在哪里执行 | 样本容器、算法与播放器输出 | 分段后端；整文件临时缓存仅供探针，不能当低延迟上线方案 |
| ByteVC2 是否有受维护可分发解码器 | 具体库版本、源码和样本 | 选同集兼容编码，显示编码限制；禁止改标签伪装 HEVC |
| 完整发现页 API 从何而来 | drama 实现或本机应用可观察行为 | 补协议研究，记录缺失；不接不明第三方解析站填空 |
| 安全存储是否支持纯 TSX | 官方 API + 重启验证 | 会话仅驻内存；记录不能恢复，进入原生扩展决策 |

## 不随 UI 参考复制的行为

原客户端的作者打赏、作者联系方式、蓝奏公告、诊断上报与自动更新不属于本项目既有服务。侧栏保留同等级设置/账号空间，使用本项目身份；无真实公告时不造公告。首期默认无自动更新、无遥测，更新和反馈作为后续明确功能设计。
