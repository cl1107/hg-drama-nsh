# 验证与发布

## 本轮完成与未完成

已完成：版本/提交实时核对、关键源码复核、七张原图归档、计划与专题文档。未执行：NSH 初始化/check/build/test、真实 API/扫码、媒体下载/解密/播放、全平台构建。本轮没有应用代码，文档校验不能替代业务验证。

历史报告中的 39/39 测试是先前 drama 参考仓库的一次验证，不属于本项目测试通过。静态报告未运行本机客户端；本轮仅观察用户已经运行的客户端窗口，没有启动新的实例，补拍因锁屏失败。

## 最小验证循环

P0 使用隔离的固定版 nsh。初始化后运行 `nsh check`、`nsh build`、`nsh test`，再 `nsh run --target macos` 检查实际窗口；flags 先查本版帮助。check 与 build 各有不同职责，读取警告，不能以单项成功代替全部。每次实现按影响执行最小相关测试，发布前执行仓库规定的完整检查。

每次命令记录 CLI 版本、环境、fixture 版本、结果、失败原因。配置和输入没变，同一失败命令至多重试一次。流式测试不要用未启用 pipefail 的管道掩盖状态，不并发启动测试进程。

## 测试分层

| 层 | 有区分度的用例与断言 |
|---|---|
| 协议/契约 | 真脱敏响应映射；大整数 ID 保精度；null video_list 行拒绝/过滤有明确规则；缺 key/尺寸/集 ID 报正确错误；空页和末页不同；异常响应不能返回假成功 |
| 签名/密钥 | 固定输入向量与字节输出；时钟/nonce 注入；合法/截断/格式错误 spade；URL CBC 与媒体 CTR 分开 |
| 媒体 | 授权小样本含音轨、IV/subsample、容器长度、时长；解密结果校验；seek/取消/损坏样本；未知 scheme 拒绝 |
| 用例 | A→B 快速切集时 A 晚到不覆盖；搜索旧请求不能追加；ended 重复事件只推进一次；退出取消同步；下载失败不置 completed |
| NSH UI | 真正 press/type/scroll：筛选后结果更新、返回保留、切集、历史续播、二维码刷新、错误重试；复用列表行不会把选择状态带给别的剧 |
| 平台实测 | 原生视频可见且可操作、音画同步、全屏/失焦/重启、签名/文件/安全存储，不由 headless 代替 |

修缺陷先复现业务失败，再修根因并转绿。对可逆文档/格式调整无需新增业务测试。

## macOS 首期必需验收

1. 打开原生窗口，深浅色、侧栏展开/折叠、960×640 和常用大窗口无遮挡。按 `UI.md` 对照同逻辑尺寸截图；标题、导航、间距、海报比例、列表密度逐项可核验。
2. 真实关键词搜索，分页不重复/漏集；同一剧详情和选集对应。快速切筛选/返回后无串内容。离线、空结果、权限受限能区别。
3. 至少 H.264 明文及一条加密来源完成解析→解密→音视频播放；HEVC 和 ByteVC2 给实际结果。播放 30 分钟、连续切 20 集、随机 seek 20 次、切质量、倍速、音量、全屏、退出重开和断网恢复，记录样本类别与结果。
4. 进度来源是实际播放事件；暂停不累计；重启到相同集与近似位置，误差目标 ≤2 秒；播放结束与临近结尾状态按统一规则（P3 确定，测试边界）。
5. 扫码由用户确认，资料验证、安全保存、重启恢复、失效重登、退出清除通过。账号 A 的请求不能带入 B；安全存储拒绝时不落明文。
6. 首期要求的发现/榜单/日历有真实接口证据，预约/收藏等读写范围明确；无接口的功能列为未完成，不能用静态数据验收。
7. 下载暂停/恢复/取消、磁盘不足、目录不可写、源 URL 过期、ETag 改变、应用重启全部可恢复或明确失败。Range/If-Range 契约不支持时重新下载，不能错误续接。删除仅影响本任务文件，失败不显示已删除；已下载媒体可离线播放。
8. 键盘焦点、中文输入法、弹层退出、图标朗读、放大字体和 reduced motion 通过；播放不会响应输入框里的空格快捷键。

## 性能记录与初始预算

先记录机器、网络、影片编码/尺寸、冷/热缓存和窗口大小。建议初始目标：本地测试 MP4 首帧 ≤1 秒，兼容 CDN 热播放首帧 ≤3 秒、seek ≤2 秒；网络不可控数据单独统计，不当算法证明。长播内存趋稳，100 次切集后无持续增长；P0 测基线再确定绝对内存预算。完整文件解密若阻塞首帧必须记录，不以“最终能播放”当性能通过。

采集 NSH trace、原生/媒体进程 CPU、峰值 RSS、帧丢失、音画同步；只在发现回归或瓶颈时扩展性能调查。UI 与媒体进程都计入资源，不把外置进程排除出内存结果。

## 全平台验收与发布

每个平台分别维护 check/build/test、打包、真机/虚拟机、账号存储、媒体编码、权限、已知限制。macOS Intel 另测实际包，不能因 arm64 本机通过宣布 universal 完成。Windows 和 Linux 必须在对应环境打包验证；iOS/Android 真机验证前后台、音频和下载；Web 验证 CORS、会话和自动播放，缺 BFF 时明确不可用范围。

首期开发包可本机签名运行；面向外部分发前核实开发者签名、公证、依赖许可证和可重现源码。GPL/媒体库链接方式与分发义务记录在组件表；不能因使用 NSH 免除上游条款。自动更新与遥测不属于首期默认能力。

完成阶段只勾选有证据的项目。阻塞必须给具体来源、动作、原因和可执行下一步；测试通过后不做无关全仓扫描。
