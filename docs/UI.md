## 布局与主题

桌面基准截图约 1568×800：侧栏约 208 px，顶部标题栏约 24 px，公告行约 44 px，内容边距约 24 px。以上是图像观测值，不等同 Retina 逻辑点；实施需记录截图像素、窗口逻辑尺寸和缩放后再对照。侧栏折叠约 64 逻辑点、最小窗口 960×640 作为初始设计值，实测后调整。

海报宽约 170 px、纵横比约 2:3，网格间距约 16 px；窗口变窄时减少列数，不能等比缩小文字。列表行内容伸展，播放/预约按钮右对齐。全窗口只有明确的内容滚动区，侧栏/顶部固定；大量海报和行列表虚拟化。筛选展开区可收起，不能在最小窗口挤掉整个结果区。

深色为初始外观，主题切换需同时支持浅色。建议 token 初值（仅限主题定义）：background `#0e0e12`、sidebar `#16161c`、card `#1e1e26`、foreground `#f1f1f4`、muted-foreground `#92929e`、border `#30303b`、primary `#ff3b68`、primary-foreground `#ffffff`、selection `#3a1d29`、rating `#f6c647`。这些是近似设计值，P1 用截图复核；浅色必须设计对应语义对，不用简单反色。页面只能消费 tokens。

字体使用平台系统中文字体。正文 14–16、次要信息 12–13、页标题约 20–22，紧凑但不缩成难读小字。间距 4/8/12/16/24，卡片圆角约 10–12，输入和按钮约 8；减少额外卡片、说明和二级标签。桌面保留系统窗口按钮，不自绘 macOS 红黄绿来模拟截图。

组件先建立：AppShell、SidebarItem、PageHeader、Button（primary/outline/ghost）、SearchField、FilterChip/FilterGroup、Tabs、PosterCard、DramaListRow、StatusView、EpisodePicker、PlayerControls、Dialog/Sheet、Toast。基于 `nsh/base` 行为层包装，明确 hover/pressed/focus/selected/disabled/loading/error。评分黄色仅用于评分，错误色与主操作区分。

## 页面行为

推荐页：关注/真人剧/推荐为独立来源条件。当前仅一个活跃视频；滚动/键盘切换应节流并取消旧加载，不后台同时发声。简介可展开；右侧点赞/评论/收藏/分享/下载/不感兴趣依能力显示，计数来自真实数据。评论和弹幕需独立接口调查，无接口不造发送成功。

找剧：搜索词输入、提交和清除；体裁、主题、设定、背景、推荐、受众、状态、时间采用上游真实枚举，图中的全部标签仅作视觉参考，不能把本地筛选全部结果当服务端完整筛选。更换条件重置分页，保留滚动/返回状态；无结果与加载失败分别呈现。

榜单：类型横 tabs 与榜单纵导航各有选中态；排行数、更新时间、热度/评分按各榜契约显示；总榜/周期选择保持结果对应。无依据时不把推荐排序标为热播榜。

新剧和日历：新剧海报卡显示剧名、标签和真实评分；日历按服务端业务时区和真实日期计算，截图日期不硬编码。日期范围支持滑动；预约有真实已预约/未预约状态，本地提醒与云预约区分。

历史/收藏/点赞：三个数据集独立状态；历史可按全部/未看完/已看完筛选，卡片叠层为当前集和真实进度；管理模式可选择/取消/删除。删除本地记录不假定同步删除云端。搜索仅过滤当前已加载数据时明确范围，或接已确认的服务端搜索。

详情与选集：尚缺截图。需要封面、标题、简介、分集与当前集、收藏和立即播放；布局先补拍再确定。选集数量大时虚拟化，区分锁定/不可用/当前/已看；总集数以接口为准。

播放器：默认自有控制条，暂停/进度/时长、音量、静音、质量、倍速、选集、全屏；窗口置顶/小窗/画中画按平台能力决定。质量名称基于真实 variant；不重复“1080p 1080P”。控制条自动隐藏须有键盘与触摸唤回，错误时保留退出和重试。

登录详见 AUTH；下载需队列、进度、状态/错误、目标和暂停/恢复/删除；设置优先外观、播放、下载目录、缓存、安全登录和关于，不复制作者身份/遥测。追更/预约页面需先补图和接口证据。

## 输入和跨平台

桌面：Tab/Shift-Tab 可达所有交互，Enter/Space 激活，Esc 关闭顶层弹层并恢复焦点；输入中空格/方向键不触发播放器快捷键。播放器获得焦点时 Space 播放、左右 seek、上下音量、F 全屏、M 静音（初始约定，补拍实际快捷键后核对）。Cmd+F 聚焦当前搜索。图标按钮有名称和必要 tooltip。

手机：共享内容与状态，导航改系统 tabs/stack，选集/筛选改 sheet，44×44 点触控，安全区和键盘避让；不能把 208 px 侧栏缩进手机。Web 按设备输入适配，桌面原生窗口控制不显示。减弱动画、字体放大和 VoiceOver 纳入验收。
